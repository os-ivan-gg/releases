# ee1os releases

Factory images and over-the-air updates for ee1os, a GrapheneOS fork. Pixel 8 Pro (husky) only for now.

- Factory images: one release per build, with the install zip and SHA-256 checksums.
- `updates`: the files the phone's Updater reads. Replaced on every release.

Install instructions and the verified boot key fingerprint: https://ee1os.com
